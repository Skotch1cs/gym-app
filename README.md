# Дневник тренировок

Простое веб-приложение для записи тренировок в зале. Работает на iPhone как обычное приложение: открой сайт в Safari → «Поделиться» → «На экран Домой».

- Записывай упражнения и подходы (вес × повторы)
- Видно, что было в прошлый раз, и отмечаются новые рекорды
- График прогресса и расчётный 1ПМ по каждому упражнению
- Работает без интернета, данные хранятся на телефоне; резервная копия в файл во вкладке «Ещё»

Без сборки и зависимостей: `index.html`, `sw.js`, `manifest.webmanifest` и иконки. Выкладывается через GitHub Pages из ветки `main`.

## Картинки упражнений

Картинки в папке `img/` взяты из открытой базы [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (общественное достояние, лицензия Unlicense). На каждой картинке две фазы движения: начало и конец. Файлы с именем `my-*.webp` сделаны из собственных фотографий тренажёров в зале.
